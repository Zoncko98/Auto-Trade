# Security

Never commit API credentials, OAuth access/refresh tokens, dashboard passwords, session secrets, account IDs, private keys, or financial account data.

Schwab authentication must be performed via its supported OAuth flow on each users own machine; this app must not collect Schwab passwords.

The archived v1.0.0 configuration contains private-network addresses only; no usable credentials are included. Keep the GitHub repository private until the portable installer is security reviewed.
