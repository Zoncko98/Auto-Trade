# Auto Trader

Self-hosted AI-supported trading research and cash-only experimental trading controls for TrueNAS SCALE.

Stable snapshot: version v1.0.0. Previous frontend version: v0.9.0-beta.

The feature/truenas-portable-installer branch provides an interactive installation wizard.
See INSTALL.md for TrueNAS installation and Schwab OAuth authorization.

All live trading is OFF by default. This software does not collect Schwab user
passwords, and it does not guarantee trading profits.

Supported external AI: private-LAN Ollama and OpenAI-compatible HTTPS APIs.
Native Anthropic and Gemini API protocols require additional adapters.
